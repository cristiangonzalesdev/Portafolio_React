# 🚀 Portafolio React — Cristian González

Portafolio personal interactivo desarrollado con **React + Vite**, creado para presentar mi perfil como **Desarrollador de Software Junior**, mis proyectos, tecnologías y experiencia de una forma más dinámica que un portafolio tradicional.

🌐 **[Ver portafolio en vivo](https://cristiangonzalesdev.github.io/Portafolio_React/)**

---

## ✨ Sobre el proyecto

Este proyecto nació como una evolución de mi portafolio anterior, buscando una experiencia más visual, interactiva y enfocada en mostrar tanto mis proyectos como las tecnologías que estoy aprendiendo.

El sitio utiliza animaciones, navegación por secciones, efectos de desplazamiento y una representación visual del stack tecnológico.

### Características principales

* 🎨 Diseño interactivo y orientado a la experiencia visual
* ⚛️ Arquitectura basada en componentes de React
* 🌀 Smooth scrolling con **Lenis**
* 🎬 Animaciones y efectos de scroll con **GSAP + ScrollTrigger**
* 🌐 Visualización interactiva del stack tecnológico con **Three.js**
* 🖱️ Cursor personalizado para escritorio
* 📱 Diseño adaptable a diferentes tamaños de pantalla
* ♿ Soporte para usuarios que prefieren reducir las animaciones
* ⚡ Construido y optimizado con **Vite**
* 🚀 Publicado mediante **GitHub Pages**

## 💻 Ejecutar el proyecto localmente

Clona el repositorio:

```bash
git clone https://github.com/cristiangonzalesdev/Portafolio_React.git
```

Entra al proyecto:

```bash
cd Portafolio_React
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Después abre en el navegador la dirección proporcionada por Vite, normalmente:

```text
http://localhost:5173
```

---

## 📦 Generar versión de producción

Para crear la versión optimizada:

```bash
npm run build
```

Esto genera la carpeta:

```text
dist/
```

También se encuentra configurado el comando:

```bash
npm run deploy
```

para publicar la aplicación mediante GitHub Pages.
